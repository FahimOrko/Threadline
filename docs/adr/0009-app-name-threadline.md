# 0009. App name is Threadline

- Status: accepted
- Date: 2026-11-06
- Supersedes: none

## Context

The app used the working title "Customer Value Review", which describes the task and not the product. The package name was the repo folder name.

## Decision

The app is called Threadline: a thread running from raw data through every calculation to the story told to the customer, which is the provenance idea. The package name is `threadline`. The name appears in the spec title, the page metadata title and the header. Lindström remains the customer and is still named in the spec and in page descriptions.

## Consequences

User-facing text says Threadline. The repo folder keeps its current name. Future docs and UI use Threadline.
